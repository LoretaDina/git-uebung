"""
1. Projekt auf GitHub erstellt und geklont: git clone
2. Drei Dateien erstellt: a.py, b.py, c.py
3. Auf GitHub gepusht: git add, git commit, git push
4. Branch feature erstellt: git checkout -b feature, c.py in feature und in main unterschiedlich geändert
5. Branches zusammengeführt: git merge feature, Konflikt in c.py gelöst, git add, git commit
6. Aktualisiertes Projekt gepusht: git push
"""
